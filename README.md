# juanelewebb-rgb.github.io

Personal site of Jua'nele Webb: research and engineering work.

- `index.html`: about page
- `research.html`: BTI REU 2026, *Engineering Drought Resilience Through Plant Architecture*
- `research/notebooks/`: R Markdown analysis notebooks (exp01–exp04)
- `assets/research/`: poster, abstract, proposal, figures
- `projects.html`: Projects page (Project OSHN; crop-light analysis of published porphyrin-film data)
- `projects/oshn-materials/`: data, extraction and analysis scripts, notebooks, and results behind the Projects page (see its README)
- `projects/3d-reconstruction/`: `recon3d`, a from-scratch 3D-reconstruction pipeline (SfM, dense stereo, Poisson mesh, texturing) with notebooks and docs

Raw experimental data is not included; it's available on request.
