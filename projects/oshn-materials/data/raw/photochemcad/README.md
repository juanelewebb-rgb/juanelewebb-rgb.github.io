# PhotochemCAD spectra

Measured absorption spectra from the PhotochemCAD database:
Taniguchi, M.; Lindsey, J. S. "Database of Absorption and Fluorescence Spectra
of >300 Common Compounds for use in PhotochemCAD." Photochem. Photobiol. 94,
290–327 (2018).

Download each compound's "Absorption spectrum (TXT)" from its page and save it
here unchanged. Starting set:

| Compound | Page |
|---|---|
| Zinc phthalocyanine (ZnPc, S04) | https://www.photochemcad.com/databases/common-compounds/phthalocyanines/znpc |
| Chlorophyll a | https://www.photochemcad.com/databases/common-compounds/chlorins-bacteriochlorins/chlorophyll-a |
| ZnTPP | https://www.photochemcad.com/databases/common-compounds/porphyrins/zntpp |
| H2TPP | https://www.photochemcad.com/databases/common-compounds/porphyrins/h2tpp |

These are solution spectra (each page lists its solvent). Film spectra shift and
broaden, so results here screen candidates; they do not predict films.
Reuse terms for republishing these spectra are not yet confirmed (docs/source_log.md).
